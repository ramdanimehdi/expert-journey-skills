# خطافات بصرية قابلة للتنفيذ

اختر لقطة مرتبطة بالشرح، لا صدمة منفصلة عنه. الأمثلة التالية أفكار جديدة مكيّفة للمدربين وليست بيانات عن نتائج أداء.

| الهدف | المشهد | تطبيق تدريبي |
|---|---|---|
| إبراز خطأ | بطاقة كبيرة بقلم ثم تعديلها | تحويل عنوان غامض إلى نتيجة أوضح |
| مقارنة | ورقتان أو شاشتان بتسميات واضحة | نص قبل المراجعة وبعدها، دون اختلاق نتيجة عميل |
| شرح نظام | منظر علوي لبطاقات تتحرك على المكتب | ترتيب التسجيل والتسليم والمتابعة |
| إثبات عمل | لقطة شاشة حقيقية مأذون بها | مثال على قالب بناه صاحب المشروع مع إخفاء البيانات |
| فتح سؤال | كشف ورقة أو أداة مرتبطة بالموضوع | ما الذي يجب تجهيزه قبل الورشة؟ |
| بداية عملية | اليد تضع قائمة فحص بجانب الحاسوب | 4 عناصر يلزم تأكيدها قبل نشر الصفحة |
| زاوية جديدة | لقطة من جانب المكتب ثم مواجهة العدسة | الانتقال من العمل إلى شرح القرار |
| موقف كوميدي | تكديس أوراق ثم ترتيب الضروري | التشتت بين الأدوات قبل تحديد المطلوب |
| عرض منتج | فتح نموذج حقيقي أو كراسة | ما الذي سيستخدمه المتعلم فعلًا؟ |
| بناء ثقة | خلف الكواليس أثناء تحضير تمرين | شرح سبب اختيار طريقة التيسير |

استخدم نصًا قصيرًا مقروءًا وأرقامًا مؤكدة. لا تعرض عوائد أو إشعارات مبيعات مصطنعة كإثبات. تجنب السقوط الخطر والأصوات المفاجئة المؤذية والتصوير دون موافقة واستنساخ صوت مشهور. أضف تفاصيل متخصصة تناسب مجال المستخدم، لا تفرض أمثلة الطعام أو التخسيس على مدرب آخر.
