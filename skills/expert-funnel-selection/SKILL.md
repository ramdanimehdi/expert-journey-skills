# اختيار الفانل


اقرأ [تعليمات رحلة الخبير المشتركة](../instructions/SKILL.md) إذا لم تُقرأ في هذه المهمة. أعدّ مهدي رمضاني هذه المهارة لخدمة جميع المدربين والخبراء؛ استخدم بيانات صاحب المشروع وصوته وهويته. لا تتحدث بوصفك مهدي، ولا توقع باسمه نيابة عن المستخدم.

اقرأ أنواع الفانلز في [فانل المبيعات للمدربين](../instructions/references/trainer-funnels.md). لا تعتمد عتبات متابعين أو سعرًا ثابتًا كقرار آلي، ولا تفترض أن منتجًا رخيصًا يغطي إعلاناته.

| المسار | متى يستحق الاختبار | التسلسل |
|---|---|---|
| مورد مجاني | حاجة لبناء قائمة وثقة حول مشكلة محددة | تعريف بالمورد ثم تسجيل ثم تسليم ثم متابعة ذات صلة |
| منتج أول منخفض السعر | قيمة واضحة وسهلة الاستهلاك مع اقتصاديات محتملة | محتوى/إعلان ثم بيع ثم دفع ثم تسليم ومتابعة |
| ورشة مباشرة | يحتاج الجمهور فهمًا وتجربة شرح قبل القرار | تسجيل ثم تذكير ثم ورشة ثم عرض اختياري ومتابعة |
| تحدٍّ | يمكن تحقيق تقدم ملموس بمهمات متتابعة وقدرة متابعة | تسجيل ثم تعليمات ثم مهمات ثم مراجعة ثم عرض مناسب |
| طلب استشارة | قيمة استشارية تحتاج تشخيصًا وتأهيلًا وتفاعلًا | محتوى/وصول ثم تعريف ثم طلب ثم مكالمة ثم عرض |
| عضوية | حاجة متكررة وقدرة مستدامة على الخدمة والاحتفاظ | تعريف ثم تسجيل ودفع دوري واضح ثم تفعيل ومتابعة |
| ورشة مسجلة دائمة | ثبت الطلب ويمكن قياس المشاهدة والمتابعة | تسجيل ثم مشاهدة ثم عرض ثم متابعة مقسمة |

اختر مسارًا واحدًا وفسّر ملاءمته للدليل المتاح. قارن بديلين فقط إذا كانت مفاضلة حقيقية. أظهر هدف كل صفحة والحدث المقاس والمتابعة، وأول أصل يلزم تجهيزه. إذا لا توجد ميزانية، اقترح اختبارًا عضويًا واقعيًا دون وعد بمبيعات سريعة.

العرض الإضافي اختياري ويكمل الشراء الأساسي؛ لا تفرض نسبة سعر منه. لا تَعِد ببناء أو ربط الصفحات. استخدم [كتابة الصفحات](../expert-funnel-pages/SKILL.md) عند طلب نصوصها.

## التعمق عند الحاجة

لتفصيل سلم القيمة والاقتصاديات والمتابعة، اقرأ [تخطيط الفانل](../plan-expert-sales-funnels/SKILL.md). استخدم فقط القسم الذي يخدم الطلب، واحفظ القرارات المعتمدة ولا تكرّر التشخيص أو الأسئلة.
