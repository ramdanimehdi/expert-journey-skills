# برومبت تصميم الصفحة


اقرأ [تعليمات رحلة الخبير المشتركة](../instructions/SKILL.md) إذا لم تُقرأ في هذه المهمة. أعدّ مهدي رمضاني هذه المهارة لخدمة جميع المدربين والخبراء؛ استخدم بيانات صاحب المشروع وصوته وهويته. لا تتحدث بوصفك مهدي، ولا توقع باسمه نيابة عن المستخدم.

ابدأ من نص الصفحة المعتمد أو استخدم [مهارة النصوص](../expert-funnel-pages/SKILL.md) إذا طلب المستخدم كتابته أيضًا. لا تجعل أداة التصميم تكتب شهادات أو تفاصيل أو عروضًا من تلقاء نفسها.

## مواصفات البرومبت

حدد نوع الصفحة، الأداة التي اختارها المستخدم، الهوية والمقاس المتجاوب، والهدف. استخدم RTL عربي حقيقي، وCairo افتراضيًا أو خط المستخدم، وحقول الهاتف والبريد والروابط LTR ضمن السياق العربي. أعط النص الحرفي لكل قسم وزر، وصف الصورة ومكانها دون اختراع صورة لصاحب المشروع، وأبقِ المحتوى قابلًا للتعديل عندما تسمح الأداة.

اطلب: تصميمًا يبدأ من الهاتف، تباينًا مناسبًا، تسميات حقول مفهومة، حالات خطأ وتحميل ونجاح، تنقل لوحة مفاتيح، هوامش آمنة، ضغط صور، وعدم تشغيل حركة أو متتبعات تلقائيًا. لا تدّعِ أن اسم الأداة وحده يضمن جمالًا أو تحويلًا أعلى.

## التسجيل والربط

حدد أين ترسل البيانات وما الرابط التالي فقط إذا قدم المستخدم تكاملًا موثقًا أو اختار ربطه. عند غياب الربط ضع تعليمات صريحة: «لا تعرض نجاح التسجيل أو رسالة تم الإرسال قبل تأكيد الحفظ؛ وضّح أن النموذج يحتاج إعداد الربط». لا تضمن أرقام وصول أو نص «لن نرسل رسائل» دون سياسة فعلية.

اجعل روابط الخصوصية والشروط والدعم ذات الصلة موجودة. الدفع والاشتراك والـUpsell يحتاج موافقة واضحة دون إخفاء الرفض أو تحديد إضافة مدفوعة مسبقًا. العد التنازلي يرتبط بموعد حقيقي مع منطقة زمنية ولا يعاد ضبطه لخلق استعجال.

## المخرج

برومبت واحد جاهز للنسخ: مواصفات عامة، المحتوى المعتمد كاملًا، توزيع كل قسم، السلوك والربط المتاح، الأصول المطلوبة، ثم فحص الهاتف وRTL والروابط والنموذج. علّم النواقص خارج المحتوى الجاهز. تسليم البرومبت لا يعني بناء الموقع أو نشره.

## التعمق عند الحاجة

لتفصيل العناصر والحقول وحالات الدفع والوصول والانتقال، اقرأ [وصفات الفانل](../assemble-expert-funnel-recipes/SKILL.md). استخدم فقط القسم الذي يخدم الطلب، واحفظ القرارات المعتمدة ولا تكرّر التشخيص أو الأسئلة.
